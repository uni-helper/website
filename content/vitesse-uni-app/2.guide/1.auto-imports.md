模板默认显式导入所有依赖，不内置自动导入。

要在模板里启用自动导入，必须自己安装并注册 [unplugin-auto-import](https://github.com/unplugin/unplugin-auto-import)。

## 添加自动导入

```bash
pnpm i -D unplugin-auto-import
```

```ts [vite.config.ts]
import AutoImport from 'unplugin-auto-import/vite'
import { defineConfig } from 'vite'

export default defineConfig({
  plugins: [
    AutoImport({
      imports: ['vue', '@vueuse/core', 'uni-app'],
    }),
  ],
})
```

注册后可以直接使用 Vue 的 Reactivity API 与 uni-app 的页面生命周期，不用写 `import`。

## 按目录自动导入

`unplugin-auto-import` 默认不处理项目目录。需要自动导入 `composables/`、`utils/` 等目录时，用它的 `dirs` 选项：

```ts [vite.config.ts]
AutoImport({
  imports: ['vue', '@vueuse/core', 'uni-app'],
  dirs: ['src/composables', 'src/utils'],
})
```

组件不在这套自动导入的范围内。模板里的组件仍然要显式导入。

## 类型声明

`unplugin-auto-import` 会生成 `auto-imports.d.ts`。把生成的文件加进 `tsconfig.json` 的 `include`，编辑器才能识别自动导入的符号。
