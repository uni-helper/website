平台别名在 `unh.config.ts` 的 `platform.alias` 里配置。别名用于简化命令行操作，也用于精简 `package.json` 的 `scripts`。

## 配置

```ts [unh.config.ts]
import { defineConfig } from '@uni-helper/unh'

export default defineConfig({
  platform: {
    // 设置默认平台
    default: 'h5',
    // 配置平台别名，一个平台可以配多个
    alias: {
      'mp-weixin': ['wx'],
      'mp-alipay': ['ali', 'alipay'],
    },
  },
})
```

## 使用

不写平台时，`unh dev` 使用 `platform.default`：

```bash [terminal]
unh dev
# 等同于: unh dev h5
```

写别名时，`unh` 先解析成完整平台名：

```bash [terminal]
unh dev wx
# 等同于: unh dev mp-weixin

unh dev ali
# 等同于: unh dev mp-alipay

unh dev alipay
# 等同于: unh dev mp-alipay
```

## 配置项

### platform.default

::field{name="default" type="Platform" defaultValue="'h5'"}
未指定平台时使用的平台
::

### platform.alias

::field{name="alias" type="Record<Platform, string | string[]>" defaultValue="{}"}
平台别名。每个平台可以配一个别名，也可以配多个
::
