## 插件特性

- 条件编译注释语法高亮，多平台分色显示。
- 未知平台错误提示，并推测最接近的正确写法。
- 条件编译注释块折叠，支持一键折叠其他平台。
- 支持 Vue、JS、TS、CSS、HTML 等文件类型。

## 使用

安装插件后重启 VS Code 即可，不需要额外配置。

## 自定义高亮

配置文件：`.vscode/settings.json`。

配置项：`uni-highlight.platform`。

它可以做三件事：

- 覆盖原有的高亮颜色。
- 添加新平台与颜色。
- 增加平台说明。

只写颜色：

```json [.vscode/settings.json]
{
  "uni-highlight.platform": {
    "MP-DINGTALK": "#41b883"
  }
}
```

同时写颜色和说明：

```json [.vscode/settings.json]
{
  "uni-highlight.platform": {
    "MP-DINGTALK": {
      "color": "#41b883",
      "label": "钉钉"
    }
  }
}
```
