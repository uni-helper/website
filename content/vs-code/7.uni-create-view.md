本扩展从右键菜单创建页面与组件。创建页面时，自动写入 `pages.json`。

## 插件特性

- 创建页面、分包页面，自动向上查找 `pages.json` 并写入。
- 可深度创建目录，写入 `pages.json` 后仍保留文件里的注释。
- 可配置 `vue2`、`vue3`、`composition-api(vue2)` 模板，`vue3` 支持 `<script setup>`。
- 可以用自己写的模板文件替代内置模板，页面与组件各一份。
- 可以切换生成 `.vue` 或 `.nvue`，`.nvue` 使用原生渲染对应的模板。
- 可配置 `css`、`scss`、`less`、`stylus`、`sass` 预处理器。
- `typescript` 是默认开发语言，可以在设置里关闭。

使用 `composition-api(vue2)` 模板时，建议配合 [uni-composition-api](https://github.com/hairyf/uni-composition-api)。

## 基本使用

在目录上右键，选择创建类型：组件、页面或分包页面。

输入时用空格分隔视图名称与页面名称。页面名称写进 `navigationBarTitleText`。

## 分包页面

从 1.3.0 起可以创建分包页面，扩展会自动写入 `subPackages` 字段。

::alert{type="warning"}
用 CLI 创建的项目必须给 `package.json` 加上 `--minimize` 参数，否则分包功能不可用。参考[官方文档](https://uniapp.dcloud.io/collocation/pages?id=subpackages)。
::

## 配置项

所有配置项都在 `.vscode/settings.json` 里。

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `create-uniapp-view.typescript` | `boolean` | `true` | 创建视图时是否默认使用 TypeScript |
| `create-uniapp-view.directory` | `boolean` | `false` | 是否创建同名文件夹 |
| `create-uniapp-view.name` | `"index"` 或 `"与文件夹同名"` | `"index"` | 文件夹中生成的文件名 |
| `create-uniapp-view.style` | `css`、`scss`、`less`、`stylus`、`sass` | `"css"` | CSS 预处理器类型 |
| `create-uniapp-view.scoped` | `boolean` | `true` | 是否使用 `<style scoped>` |
| `create-uniapp-view.setup` | `boolean` | `true` | 创建 `vue3` 模板时是否使用 `<script setup>` |
| `create-uniapp-view.template` | `vue2`、`vue3`、`composition-api(vue2)` | `"vue3"` | 使用的模板 |
| `create-uniapp-view.customPageTemplate` | `string` | `""` | 自定义页面模板的路径 |
| `create-uniapp-view.customComponentTemplate` | `string` | `""` | 自定义组件模板的路径 |
| `create-uniapp-view.nvue` | `boolean` | `false` | 生成 `.nvue` 文件并使用 nvue 模板 |

自定义模板的路径以工作区根目录为基准。留空时使用内置模板。设置之后忽略 `template` 配置。

```json [.vscode/settings.json]
{
  "create-uniapp-view.typescript": true,
  "create-uniapp-view.style": "scss",
  "create-uniapp-view.template": "vue3",
  "create-uniapp-view.setup": true,
  "create-uniapp-view.nvue": false
}
```
