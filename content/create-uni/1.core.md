本工具用一条命令创建基于 Vite + Vue 3 的 uni-app 项目。模板、插件、模块、组件库与原子化 CSS 都可以在创建时选择。

## 快速开始

### 交互式创建

不带项目名执行时，脚手架依次询问项目名、模板与各项配置。

::stack
:pm-create{name="uni@latest"}

::alert
建议加标记名（`@latest`）。不加时，npm 可能解析到缓存的过时版本。
::
::

### 命令行创建

配置项全部通过参数传入时，不再进入交互提问。

:pm-create{name="uni <项目名称> --ts -m pinia -m uniUse -u ano -c unocss -e"}

### 图形界面

用桌面窗口代替终端提问，适合不想记参数的时候。

:pm-create{name="uni --gui"}

详见 [图形化界面](/create-uni/gui)。

### 检查项目环境

```shell
npx @create-uni/info@latest
```

必须在 uni-app 项目根目录下执行。其他目录下会提示未检测到 `@dcloudio/uni-app`，无法收集依赖信息。也可以用 `create-uni --info` 调用同一份逻辑。

详见 [环境信息](/create-uni/info)。

## 命令行参数

| 配置项 | 参数 | 别名 | 可选值 |
| :---: | :---: | :---: | :---: |
| 模板 | `--templateType` | `-t` | 见[模板](#模板) |
| TypeScript | `--needsTypeScript` | `--ts` | —— |
| 插件 | `--pluginList` | `-p` | 见[插件](#插件) |
| 模块 | `--moduleList` | `-m` | 见[模块](#模块) |
| UI 组件库 | `--UIName` | `--ui`、`-u` | 见[组件库](#组件库) |
| 原子化 CSS | `--cssType` | `--css`、`-c` | 见[原子化 CSS](#原子化-css) |
| ESLint | `--needsEslint` | `--eslint`、`-e` | —— |
| 图形界面 | `--gui` | `-g` | —— |
| 项目环境信息 | `--info` | `-i` | —— |
| 覆盖同名目录 | `--force` | `-f` | —— |
| 帮助 | `--help` | `-h` | —— |

`-p`、`-m`、`-u` 可以重复传多个值。`--force` 遇到同名目录时直接覆盖，不再询问。

## 原子化 CSS

`unocss` 与 `tailwindcss` 互斥，只能选一个，也可以都不使用。

| 名称 | 描述 | 参数名 |
| :---: | :---: | :---: |
| [unocss](https://unocss.dev/) | 即时按需的原子级 CSS 引擎 | `unocss` |
| [tailwindcss](https://tw.weapp.dev/) | 通过 weapp-tailwindcss 适配小程序的原子化 CSS 框架 | `tailwindcss` |

不传 `--cssType` 时不使用原子化 CSS。

## 开发

- Node.js 24 及以上。仓库未固定具体版本。
- pnpm 12.3.4，见根 `package.json` 的 `packageManager`。
- Rust stable，仅 `packages/gui` 需要。仓库未固定版本，按当前依赖解析结果需要 1.89 及以上。

```shell
pnpm i            # 安装依赖，postinstall 会把 create-uni、@create-uni/info、@create-uni/gui link 到根目录
pnpm build:core   # 构建 CLI 到 packages/core/dist/outfile.cjs
pnpm play         # 用刚构建的产物跑一次，等价于 pnpm create-uni
```
